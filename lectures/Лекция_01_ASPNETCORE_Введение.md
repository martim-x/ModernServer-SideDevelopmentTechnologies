## 14-16. Kestrel, HttpContext, этапы запуска
14. **Kestrel** — кроссплатформенный HTTP-сервер, принимает низкоуровневый запрос и на его основе
   создаёт объект `HttpContext`, содержащий всю информацию о запросе (в т.ч. Request и Response).
   Альтернативы Kestrel: **IIS HTTP Server** (только под Windows) и **HTTP.sys** (только под Windows).
15. **HttpContext** — объект, создаваемый HTTP-сервером, содержит исчерпывающую информацию
   о соединении, запросе, будущем ответе.
16. Этапы подготовки и запуска приложения: **generate** -> **restore** -> **build** -> **run**.

var builder = WebApplication.CreateBuilder(args);   // создаем WebApplicationBuilder (паттерн builder)

## 21-25. Ключевые понятия
21. **WebApplication** — резидентный объект (ядро приложения, содержащее http-сервер Kestrel);
    параметризация на основе **паттерна builder** (экземпляр `WebApplicationBuilder`);
    экземпляр создаётся методом `WebApplicationBuilder.Build()`; приложение запускается
    методом `WebApplication.Run()`.
22. `WebApplication.UseXXX` — подключение middleware-элементов.
23. `WebApplication.Environment` — переменные окружения (`ASPNETCORE_ENVIRONMENT`).
24. `WebApplicationBuilder` — конфигурирование, журналирование, сервисы, Kestrel.
    В предыдущих версиях: классы `Startup`, `IHostBuilder`, `IHost`.
25. `Program.cs` — протоколирование (журналирование), конечная точка, обработчик запросов, маршрутизация.

## 26. Журналирование и вторая конечная точка — код со скриншота
```csharp
builder.Services.AddHttpLogging(o => {              // вывод в журнал
    o.LoggingFields = HttpLoggingFields.RequestMethod      // request метод
                  | HttpLoggingFields.RequestPath        // request uri
                  | HttpLoggingFields.ResponseStatusCode // response status
                  | HttpLoggingFields.ResponseBody;      // response тело
});

app.MapGet("/", () => "Hello World!");                                                 // задаем конечную точку 1
app.MapGet("/person", () => new Person("Kamala", "Harris", new DateTime(1964,10,20)));  // задаем конечную точку 2
```
